## Open questions from studies

- **Observable-matched slicing nodes (Phase 3c, one experiment):** minimize the
  kick error (or a luminosity-weighted error) directly over `{z_k, w_k}` at
  fixed `ns` to get the true lower bound the slicing rules should be scored
  against. The Gauss-Hermite result is direct evidence that source-fidelity
  objectives and kick accuracy come apart. Per-machine result, acceptable for a
  fixed design point; hypothesis, not established practice.
- **Hadron-side slicing stopping criterion:** Furman's `Q ~ 4/sqrt(tau)`
  applies to the electron ring; the proton ring has no comparable `tau`, so
  nothing masks its residual. Pick a long-term emittance-growth rate or
  diffusion coefficient instead.
- **`:equal_width` carries a second convergence parameter** (`slice_width`): a
  user who fixes the width will see convergence stall. Consider deriving the
  width from `ns` by default, or rejecting a fixed width above some `ns`.
